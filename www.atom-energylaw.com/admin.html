Publishing Notes

Use Save JSON File to write the updated content file directly from the admin page when your browser supports it. If not, use Download JSON and replace site-content.json manually before you deploy. Uploaded images are stored inside the content data, so the admin does not need separate image URLs. The public pages also read the newest browser draft automatically, so page and section visibility changes can preview immediately after you edit them here.
